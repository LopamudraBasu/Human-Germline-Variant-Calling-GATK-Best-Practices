# Raw Sequencing Data

The original FASTQ files are not included in this repository because of GitHub file size limitations.

## Sample

- NIST7035
- Paired-end Illumina sequencing

## Download

The sequencing reads can be downloaded from the NCBI Sequence Read Archive (SRA).

After downloading, place the FASTQ files in this directory.

Expected filenames:

```
NIST7035_TAAGGCGA_L001_R1_001.fastq.gz
NIST7035_TAAGGCGA_L001_R2_001.fastq.gz
```
